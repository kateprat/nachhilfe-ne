1 · What do the letters mean?

A letter stands for a number that we don't know yet, or that is allowed to change. That's all. You calculate with it exactly like with a number.

Substituting into x

\(f(x) = x^2 - 2x + 3\) is a rule: “Take a number x and calculate with it.” \(f(2)\) means: write 2 everywhere you see x.

$$f(2) = 2^2 - 2\cdot 2 + 3 = 4 - 4 + 3 = 3$$

Try it yourself: what is \(f(-1)\)?

\(f(-1) = (-1)^2 - 2\cdot(-1) + 3 = 1 + 2 + 3 = 6\). Careful: brackets around negative numbers!

Two kinds of letters

  • x moves: it stands for “any position on the x-axis”. Each x gives a different function value.
  • \(\m\) and \(\q\) are fixed numbers. For one particular line they have a value, we just don't know it yet. These are exactly the numbers we are looking for in the tangent exercises.

The line \(g(x) = \m\cdot x + \q\)

m = slope: go 1 to the right and the line goes m up (down if m is negative).
q = y-intercept: where the line crosses the y-axis, at the point \((0, \q)\).

Move the sliders: m turns the line, q moves it up and down.

Does a point lie on the line? → Substitute

A point \(P = (x_P, y_P)\) lies on g if \(g(x_P) = y_P\) is true.

Example: \(g(x) = -3x + 5\) and \(P = (2, -1)\): \(g(2) = -3\cdot 2 + 5 = -1\). ✓ P lies on g.

Does \((1, 1)\) lie on g?

\(g(1) = -3 + 5 = 2 \neq 1\). No.

When m and q are still unknown

Then substituting a point gives an equation between m and q. We solve it for q. This is step 1 in almost every exercise.

$$P = (1,-3) \text{ lies on } g:\qquad \m\cdot 1 + \q = -3 \iff \q = -\m - 3$$

Setting equal and the discriminant

Where parabola f and line g meet, they are at the same height: \(f(x) = g(x)\). This gives a quadratic equation \(ax^2 + bx + c = 0\). Its discriminant \(D = b^2 - 4ac\) tells you how many meeting points there are (chapter 14):

  • \(D \gt 0\): two intersection points. The line cuts the parabola.
  • \(D = 0\): exactly one point. The line is a tangent. Then \(x = -\frac{b}{2a}\).
  • \(D \lt 0\): no point. The line misses.

2 · The recipe for tangents

Almost all exercises A2–A8 use the same 7 steps. Only step 1 changes, depending on what is given.

  1. Set-up (Ansatz)\(t(x) = \m x + \q\)Substitute what is given.Slope given → substitute m. Point given → substitute it and solve for q.
  2. Set equal\(f(x) = t(x)\)Where do parabola and line meet?
  3. Standard form\(ax^2 + bx + c = 0\)Everything on one side, ordered by x², x, number. Read off a, b, c.
  4. Discriminant = 0\(b^2 - 4ac = 0\)Tangent means: exactly one point of contact.
  5. Solve for the number you are looking for (q or m)Often another quadratic equation → quadratic formula.
  6. Write down the tangentPut the numbers you found into \(t(x) = \m x + \q\).
  7. Point of contact\(x = -\frac{b}{2a}\), then \(y = t(x)\)With D = 0 the quadratic formula gives only this one solution.

How to write it down in the exam

Use the words from the script: “Ansatz: …”, “Since P lies on t, …”, “⇔”, “So …”, “The tangent we are looking for is …”. No calculator: leave fractions as they are. Check: substitute the point of contact into f as well, you must get the same y.

A2

worked
Find the tangent with slope −3 to the parabola \(f(x) = x^2 - 2x + 3\) and its point of contact.
  1. STEP 1

    Set-up

    The slope is given, so \(\m = -3\). Only \(\q\) is still unknown.

    $$t(x) = -3x + \q$$
  2. STEP 2

    Set equal

    Where line and parabola meet, they are at the same height.

    $$-3x + \q = x^2 - 2x + 3$$
  3. STEP 3

    Standard form

    Bring everything to the side with x² (there x² is positive), then sort.

    $$\begin{aligned} 0 &= x^2 - 2x + 3x + 3 - \q \\ 0 &= x^2 + 1\cdot x + (3 - \q) \end{aligned}$$

    So \(a = 1\), \(b = 1\), \(c = 3 - \q\).

  4. STEP 4

    Discriminant = 0

    Tangent = exactly one point of contact = exactly one solution = D is 0.

    $$D = b^2 - 4ac = 1^2 - 4\cdot 1\cdot(3 - \q) = 0$$
  5. STEP 5

    Solve for q

    Expand the bracket: \(-4\cdot 3 = -12\) and \(-4\cdot(-\q) = +4\q\).

    $$\begin{aligned} 1 - 12 + 4\q &= 0 \\ 4\q &= 11 \\ \q &= \tfrac{11}{4} \end{aligned}$$
  6. STEP 6

    Write down the tangent

    $$t(x) = -3x + \tfrac{11}{4}$$
  7. STEP 7

    Point of contact

    From step 3: a = 1, b = 1. With D = 0, \(x = -\frac{b}{2a}\). Then substitute x into t.

    $$x = -\frac{1}{2\cdot 1} = -\tfrac12, \qquad y = t\!\left(-\tfrac12\right) = \tfrac32 + \tfrac{11}{4} = \tfrac{17}{4}$$

    Check in f: \(f(-\tfrac12) = \tfrac14 + 1 + 3 = \tfrac{17}{4}\) ✓

The tangent is \(t(x) = -3x + \frac{11}{4}\), point of contact \(P = \left(-\frac12, \frac{17}{4}\right) = (-0.5;\ 4.25)\). Check it in the picture (example “A2”).

A3

worked
Find all tangents to the parabola \(f(x) = x^2 - 2x + \frac{25}{16}\) that pass through the origin; give the point of contact for each.
  1. STEP 1

    Set-up

    The tangent passes through \((0, 0)\). Substitute: \(t(0) = 0\). That settles \(\q\); now \(\m\) is what we're looking for.

    $$\m\cdot 0 + \q = 0 \iff \q = 0, \qquad\text{so}\qquad t(x) = \m x$$
  2. STEP 2

    Set equal

    $$\m x = x^2 - 2x + \tfrac{25}{16}$$
  3. STEP 3

    Standard form

    Move \(\m x\) to the right and combine the two x-terms: \(-2x - \m x = (-2 - \m)\,x\). Brackets around b, because m is inside.

    $$0 = x^2 + (-2 - \m)\,x + \tfrac{25}{16}$$

    So \(a = 1\), \(b = -2 - \m\), \(c = \frac{25}{16}\).

  4. STEP 4

    Discriminant = 0

    $$D = (-2 - \m)^2 - 4\cdot 1\cdot \tfrac{25}{16} = (-2-\m)^2 - \tfrac{25}{4} = 0$$
  5. STEP 5

    Solve for m

    \((-2-\m)^2 = 4 + 4\m + \m^2\) (binomial formula). Multiply by 4 to get rid of the fraction. Then the quadratic formula, this time for m.

    $$\begin{aligned} \m^2 + 4\m + 4 - \tfrac{25}{4} &= 0 \quad \mid \cdot 4 \\ 4\m^2 + 16\m - 9 &= 0 \\ \m_{1,2} &= \frac{-16 \pm \sqrt{256 + 144}}{8} = \frac{-16 \pm 20}{8} \\ \m_1 = \tfrac12, &\quad \m_2 = -\tfrac92 \end{aligned}$$

    Two values for m → two tangents. This happens when the point lies outside the parabola.

  6. STEP 6

    Write down the tangents

    $$t_1(x) = \tfrac12 x, \qquad t_2(x) = -\tfrac92 x$$
  7. STEP 7

    Points of contact

    \(x = -\frac{b}{2a}\) with \(b = -2 - \m\) gives \(x = \frac{2 + \m}{2}\). Substitute each m separately.

    $$\begin{aligned} \m_1 = \tfrac12: &\quad x = \tfrac{2 + 1/2}{2} = \tfrac54, \quad y = \tfrac12\cdot\tfrac54 = \tfrac58 \\ \m_2 = -\tfrac92: &\quad x = \tfrac{2 - 9/2}{2} = -\tfrac54, \quad y = -\tfrac92\cdot\left(-\tfrac54\right) = \tfrac{45}{8} \end{aligned}$$
\(t_1(x) = \frac12 x\) with \(P_1 = \left(\frac54, \frac58\right) = (1.25;\ 0.625)\) and \(t_2(x) = -\frac92 x\) with \(P_2 = \left(-\frac54, \frac{45}{8}\right) = (-1.25;\ 5.625)\).

A4 (a)

worked
Find the equation \(t(x) = \m x + \q\) of the tangent to \(f(x) = x^2\) at the point \(Q = \left(\frac12, \frac14\right)\).
  1. STEP 1

    Set-up

    Q lies on t, so \(t(\tfrac12) = \tfrac14\). Solve for q.

    $$\m\cdot\tfrac12 + \q = \tfrac14 \iff \q = \tfrac14 - \tfrac12\m$$
  2. STEP 2

    Set equal

    $$x^2 = \m x + \q$$
  3. STEP 3

    Standard form

    $$x^2 - \m x - \q = 0$$

    So \(a = 1\), \(b = -\m\), \(c = -\q\).

  4. STEP 4

    Discriminant = 0

    $$D = (-\m)^2 - 4\cdot 1\cdot(-\q) = \m^2 + 4\q = 0$$
  5. STEP 5

    Replace q and solve for m

    Now step 1 comes back: for q we put in \(\tfrac14 - \tfrac12\m\). Then only one unknown is left.

    $$\begin{aligned} \m^2 + 4\left(\tfrac14 - \tfrac12\m\right) &= 0 \\ \m^2 - 2\m + 1 &= 0 \\ (\m - 1)^2 &= 0 \iff \m = 1 \end{aligned}$$

    And \(\q = \tfrac14 - \tfrac12\cdot 1 = -\tfrac14\).

  6. STEP 6

    Write down the tangent

    $$t(x) = x - \tfrac14$$
  7. STEP 7

    Point of contact

    For free here: Q itself is the point of contact. Check: \(t(\tfrac12) = \tfrac12 - \tfrac14 = \tfrac14\) ✓

\(t(x) = x - \frac14\).

A4 (b)

your turn
General point \(P = (p, p^2)\) on the standard parabola \(f(x) = x^2\). Find the tangent \(t(x) = \m x + \q\) to f at the point P.
p is just a number we don't fix. Calculate exactly as in (a), only with p instead of ½.
  1. STEP 1

    Set-up: P lies on t

    As in (a): \(t(p) = p^2\), solve for q.

    $$\m p + \q = p^2 \iff \q = p^2 - \m p$$
  2. STEPS 2–4

    Set equal, standard form, D = 0

    Exactly as in (a), this doesn't change.

    $$x^2 - \m x - \q = 0, \qquad D = \m^2 + 4\q = 0$$
  3. STEP 5

    Replace q, solve for m

    Hint: at the end there's a binomial formula.

    $$\begin{aligned} \m^2 + 4(p^2 - \m p) &= 0 \\ \m^2 - 4p\,\m + 4p^2 &= 0 \\ (\m - 2p)^2 &= 0 \iff \m = 2p \end{aligned}$$

    And \(\q = p^2 - 2p\cdot p = -p^2\).

  4. STEP 6

    Tangent

    $$t(x) = 2p\cdot x - p^2$$
This is Proposition 17.2.4: slope = twice the x-coordinate, y-intercept = minus the y-coordinate. You need this shortcut in A5.

A5

your turn
Using Proposition 17.2.4: give the tangents to the standard parabola \(f(x) = x^2\) at the points \(A = (-2, 4)\), \(B = (3, 9)\), \(C = (1, 1)\), \(D = (\frac12, \frac14)\), \(E = (-\frac32, \frac94)\), \(O = (0, 0)\).
  1. RULE

    The shortcut

    p is the x-coordinate of the point. Substitute into \(t(x) = 2p\cdot x - p^2\). Careful with negative p: \((-2)^2 = 4\), so \(-p^2 = -4\).

  2. A

    \(A = (-2, 4)\), so \(p = -2\)

    $$t_A(x) = 2\cdot(-2)\cdot x - (-2)^2 = -4x - 4$$
  3. B

    \(B = (3, 9)\)

    $$t_B(x) = 6x - 9$$
  4. C

    \(C = (1, 1)\)

    $$t_C(x) = 2x - 1$$
  5. D

    \(D = (\frac12, \frac14)\)

    $$t_D(x) = x - \tfrac14 \quad\text{(same as in A4 (a)!)}$$
  6. E

    \(E = (-\frac32, \frac94)\)

    $$t_E(x) = 2\cdot\left(-\tfrac32\right) x - \tfrac94 = -3x - \tfrac94$$
  7. O

    \(O = (0, 0)\)

    $$t_O(x) = 0\cdot x - 0 = 0 \quad\text{(this is the x-axis)}$$
Sketch the standard parabola with all six tangents, or draw them in GeoGebra. Each line touches the parabola exactly at its point.

A6

your turn
(a) Find all tangents to the standard parabola \(f(x) = x^2\) that pass through \(A = (1, -3)\). A does not lie on the parabola. (b) Give the points of contact.
Here the 2nd method from the script = our recipe. The 1st method is below.
  1. STEP 1

    Set-up: A lies on t

    \(t(1) = -3\). Solve for q.

    $$\m\cdot 1 + \q = -3 \iff \q = -\m - 3$$
  2. STEPS 2–3

    Set equal, standard form

    As in A4.

    $$x^2 = \m x + \q \iff x^2 - \m x - \q = 0$$
  3. STEP 4

    Discriminant = 0

    $$D = \m^2 + 4\q = 0$$
  4. STEP 5

    Replace q, solve for m

    $$\begin{aligned} \m^2 + 4(-\m - 3) &= 0 \\ \m^2 - 4\m - 12 &= 0 \\ \m_{1,2} &= \frac{4 \pm \sqrt{16 + 48}}{2} = \frac{4 \pm 8}{2} \\ \m_1 = 6, &\quad \m_2 = -2 \end{aligned}$$

    And \(\q_1 = -6 - 3 = -9\), \(\q_2 = 2 - 3 = -1\).

  5. STEP 6

    Tangents

    $$t_1(x) = 6x - 9, \qquad t_2(x) = -2x - 1$$
  6. STEP 7

    Points of contact (b)

    \(b = -\m\), so \(x = -\frac{b}{2a} = \frac{\m}{2}\). And y = x², because the point lies on the standard parabola.

    $$\m_1 = 6:\ x = 3,\ P_1 = (3, 9) \qquad \m_2 = -2:\ x = -1,\ P_2 = (-1, 1)$$
\(t_1(x) = 6x - 9\) touches at \((3, 9)\), \(t_2(x) = -2x - 1\) touches at \((-1, 1)\).

1st method (with the shortcut from A4 (b)): we need p with \(t_p(1) = -3\): \(2p - p^2 = -3 \iff p^2 - 2p - 3 = 0 \iff p = 3\) or \(p = -1\). Same tangents, same points of contact.

Check it in the picture: example “x²”, point A at (1, −3).

A7

your turn
(a) Find all tangents to \(f(x) = \frac14(x + 3)^2 + 1\) that pass through \(P = (-2, -1)\). (b) Find each point of contact.
  1. STEP 1

    Set-up: P lies on t

    $$\m\cdot(-2) + \q = -1 \iff \q = 2\m - 1$$
  2. STEP 2

    Set equal

    $$\tfrac14(x + 3)^2 + 1 = \m x + \q$$
  3. STEP 3

    Standard form

    Hint: first multiply by 4, then the fraction is gone. \((x+3)^2 = x^2 + 6x + 9\) (binomial formula). Combine the x-terms as in A3.

    $$\begin{aligned} (x + 3)^2 + 4 &= 4\m x + 4\q \\ x^2 + 6x + 13 &= 4\m x + 4\q \\ x^2 + (6 - 4\m)\,x + (13 - 4\q) &= 0 \end{aligned}$$

    So \(a = 1\), \(b = 6 - 4\m\), \(c = 13 - 4\q\).

  4. STEP 4

    Discriminant = 0

    Expand, then divide everything by 4: smaller numbers.

    $$\begin{aligned} (6 - 4\m)^2 - 4(13 - 4\q) &= 0 \\ 36 - 48\m + 16\m^2 - 52 + 16\q &= 0 \quad\mid :4 \\ 4\m^2 - 12\m - 4 + 4\q &= 0 \end{aligned}$$
  5. STEP 5

    Replace q, solve for m

    $$\begin{aligned} 4\m^2 - 12\m - 4 + 4(2\m - 1) &= 0 \\ 4\m^2 - 4\m - 8 &= 0 \quad\mid :4 \\ \m^2 - \m - 2 &= 0 \\ \m_{1,2} = \frac{1 \pm \sqrt{1 + 8}}{2} = \frac{1 \pm 3}{2}, &\quad \m_1 = 2,\ \m_2 = -1 \end{aligned}$$

    And \(\q_1 = 2\cdot 2 - 1 = 3\), \(\q_2 = 2\cdot(-1) - 1 = -3\).

  6. STEP 6

    Tangents

    $$t_1(x) = 2x + 3, \qquad t_2(x) = -x - 3$$
  7. STEP 7

    Points of contact (b)

    \(x = -\frac{b}{2a} = -\frac{6 - 4\m}{2} = 2\m - 3\), then calculate y with t.

    $$\begin{aligned} \m_1 = 2: &\quad x = 1,\quad y = t_1(1) = 5 \\ \m_2 = -1: &\quad x = -5,\quad y = t_2(-5) = 2 \end{aligned}$$

    Check: \(f(1) = \tfrac14\cdot 16 + 1 = 5\) ✓, \(f(-5) = \tfrac14\cdot 4 + 1 = 2\) ✓

\(t_1(x) = 2x + 3\) touches at \((1, 5)\), \(t_2(x) = -x - 3\) touches at \((-5, 2)\). (c) Drawing: vertex \(S = (-3, 1)\), stretch factor ¼. Check it in the picture (example “¼(x + 3)² + 1”).

A8

your turn
Find the tangent to \(f(x) = \frac14(x + 3)^2 + 1\) at the point \(A = (-1, f(-1))\).
  1. STEP 0

    Calculate the point

    f(−1) means: substitute −1 for x.

    $$f(-1) = \tfrac14(-1 + 3)^2 + 1 = \tfrac14\cdot 4 + 1 = 2, \qquad A = (-1, 2)$$
  2. STEP 1

    Set-up: A lies on t

    $$\m\cdot(-1) + \q = 2 \iff \q = \m + 2$$
  3. STEPS 2–4

    Set equal, standard form, D = 0

    Same parabola as in A7, so exactly the same working up to here.

    $$x^2 + (6 - 4\m)\,x + (13 - 4\q) = 0, \qquad 4\m^2 - 12\m - 4 + 4\q = 0$$
  4. STEP 5

    Replace q, solve for m

    $$\begin{aligned} 4\m^2 - 12\m - 4 + 4(\m + 2) &= 0 \\ 4\m^2 - 8\m + 4 &= 0 \quad\mid :4 \\ \m^2 - 2\m + 1 = (\m - 1)^2 &= 0 \iff \m = 1 \end{aligned}$$

    And \(\q = 1 + 2 = 3\). Only one m: A lies on the parabola, so there is only one tangent.

  5. STEP 6

    Tangent

    $$t(x) = x + 3$$
  6. STEP 7

    Check

    The point of contact must be A: \(x = 2\m - 3 = -1\) ✓ and \(t(-1) = 2\) ✓

\(t(x) = x + 3\), point of contact \(A = (-1, 2)\).
